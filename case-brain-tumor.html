Brain Tumor AI Detector: a machine learning web app

A deep learning model that analyses an MRI scan and predicts the tumor type, served through a simple web app anyone can use from a link.

Machine learningHealthcareWeb app
View live project

The challenge

Machine learning models often stay inside notebooks. The goal was to take a trained image classifier and make it usable by anyone with a browser: upload a scan, get a result in seconds, and understand how confident the model is.

What we built

  • A custom CNN built with TensorFlow, trained to tell 4 tumor classes apart from 128×128 pixel MRI images
  • A web app where users upload an MRI scan and press Analyze
  • A clear result card with the predicted type and a confidence score
  • A full probability breakdown for every class, so the result is transparent
  • A visible disclaimer that the tool is for educational purposes only

The outcome

A working AI tool that anyone can try from a link. It turns a model into a product: a simple upload, a readable result and honest limits.

  • Live online, with nothing to install
  • Results shown with confidence scores, not just a label
  • Clear educational disclaimer built into the page
